# Chile Simulator — страница игры в Roblox

## Название

Основное (выбрано): **Chile Simulator**.

Roblox-поиск находит игры по словам из названия. «Chile» само по себе не говорит, что внутри рост, поэтому
для кликабельности рекомендую оставить имя, но добавить хвост с ключевыми словами:

> **Chile Simulator 📏 Get Taller Every Tap!**

(слова *simulator, tall, taller, tap* — именно так ищут такие игры; эмодзи 📏 выделяет строку в списке).

Альтернативы из брифа (если когда-нибудь захочется A/B-тест названия):

| # | Название | Комментарий |
|---|---|---|
| 1 | TALLER EVERY TAP | исходный рабочий вариант, описывает механику |
| 2 | TAP TO GET TALL | лучший «поисковый» вариант: *tap* + *tall* |
| 3 | GET TALLER | коротко, но очень общее |
| 4 | GROW TALLER | то же |
| 5 | TAP & GROW | коротко, но без «tall» |
| 6 | INFINITE HEIGHT | интригует, хорошо для «сколько можно вырасти» |
| 7 | GET HUGE | сильный, но уводит к «широким» симуляторам силы |
| 8 | TALLER SIMULATOR | ищется, но звучит скучно |
| 9 | HEIGHT SIMULATOR | ищется по «simulator» |
| 10 | TALL EVERY SECOND | эксплуатирует тренд «+1 every second» |

Итог: **Chile Simulator 📏 Get Taller Every Tap!** — сохраняет ваше имя и добавляет слова, по которым ищут.
Если когда-то решите сменить название целиком — **TAP TO GET TALL** лучший по поиску и понятности.

внизу крупно **GET TALL!** Читается даже в маленьком размере: два силуэта «плоский vs длинный» + одна фраза.

сохранив ту же композицию.
