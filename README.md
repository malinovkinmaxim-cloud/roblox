# HOP PALS

Кооперативный 2D-платформер для Roblox в духе Pico Park: команда цветных кроликов (от 2 до 8 игроков) решает головоломки только вместе.

## Что есть в игре

- **Ключ и дверь.** Возьмите ключ, донесите его до двери, а потом зайдите в дверь **все** — только тогда уровень пройден.
- **Стойка на голове.** Игроки сталкиваются и могут стоять друг на друге, так можно достать до высоких мест.
- **Ящики с числом.** Число показывает, сколько игроков должно толкать ящик одновременно (можно толкать цепочкой друг за другом).
- **Кнопки.** Открывают стены или включают мосты, пока на них стоит нужное число игроков.
- **Лифт.** Едет вверх, только когда на нём стоят все.
- **Общий экран.** Камера держит в кадре всех, и никто не может убежать от команды дальше края экрана.
- Если кто-то погиб (шипы, пропасть), уровень перезапускается для всех. `R` или кнопка ↻ перезапускает уровень вручную.

Отличия от оригинала: кролики вместо котиков, своя палитра, лифт не уезжает вниз, пока на нём хоть кто-то стоит, а требования ящиков, кнопок и лифта не превышают число игроков на сервере.

## Как запустить через Rojo

1. Установите [Rojo](https://rojo.space/docs/v7/getting-started/installation/) (CLI) и плагин Rojo для Roblox Studio.
2. В папке проекта выполните:
   ```sh
   rojo serve
   ```
3. Откройте в Roblox Studio пустой шаблон Baseplate и нажмите **Connect** в плагине Rojo. `Baseplate` и `SpawnLocation` скрипт уберёт сам при запуске.
4. Для проверки с несколькими игроками откройте вкладку **Test → Clients and Servers**, выберите 2–4 игрока и нажмите **Start**. Большинство уровней одному пройти нельзя, как и в оригинале.

Или соберите готовый файл места:

```sh
rojo build -o HopPals.rbxlx
```

Потом откройте `HopPals.rbxlx` в Studio и опубликуйте через **File → Publish to Roblox**.

## Управление

| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Ходить | A / D или ← → | стик / крестовина | кнопки ◀ ▶ |
| Прыжок | Пробел / W / ↑ | A | кнопка ⤒ |
| Заново | R | — | кнопка ↻ |

## Структура

```
src/
  shared/Config.lua        настройки: размеры, скорости, цвета
  shared/Levels.lua        уровни в виде ASCII-карт
  server/init.server.lua   игровой цикл: загрузка уровней, спавн, победа и перезапуск
  server/LevelBuilder.lua  строит уровень из ASCII-карты
  server/Mechanics.lua     ключ, дверь, кнопки, ящики, лифты, шипы
  server/CharacterFactory.lua  персонаж-кролик
  client/init.client.lua   управление, 2D-ограничение, общий экран, камера
  client/Ui.lua            интерфейс и сенсорные кнопки
  character/Animate.client.lua  анимация подпрыгивания при ходьбе
```

## Как добавить уровень

Добавьте таблицу в `src/shared/Levels.lua`. Легенда символов описана в начале файла:

```lua
{
	name = "Мой уровень",
	hint = "Подсказка для игроков",
	button = { need = 2, latch = true }, -- latch = стена остаётся открытой навсегда
	lift = { need = 99, rise = 5 },      -- 99 = все игроки
	map = {
		"                    ",
		"  S   22   b  x  K D",
		"####################",
	},
}
```
